# Raccourcis clavier

Les raccourcis ci-dessous permettent de naviguer plus rapidement dans Nexus et de faciliter le traitement des données.

## Fenêtre de visualisation

| Action | Raccourci |
|----------|----------|
| Rotation de la vue | Clic gauche + glisser |
| Zoom avant / arrière | Clic droit + glisser |
| Translation de la vue | Molette maintenue + glisser |
| Déplacement dans le temps (changement de frame) | Molette |

## Édition et navigation

| Action | Raccourci |
|----------|----------|
| Annuler la dernière action | **Ctrl + Z** |
| Rétablir l'action annulée | **Ctrl + Y** |
| Sauvegarder le trial courant | **Ctrl + S** |
| Quitter l'outil ou le mode en cours | **Échap** |

<span style="color:red">**Ne jamais utiliser Ctrl + S lorsque vous êtes sur la configuration du PC d'acquisition**</span> 

## Outils de traitement

| Action | Raccourci |
|----------|----------|
| Sélection multiple | **Ctrl + clic gauche** |
| Afficher / masquer le nom des marqueurs | **Ctrl + Espace** |
| Activer le mode Événements (création et ajustement des événements du cycle) | **Ctrl + E** |

*Lorsque le mode Événements est activé (**Ctrl + E**), le curseur devient une **flèche verticale**, permettant de créer ou modifier les événements directement sur la timeline.*
